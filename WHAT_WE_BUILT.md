## What Is This?

**Truth Drop Platform** is a complete **full-stack web application** (website) that serves as a **digital marketplace** for your constitutional knowledge codexes.

---

## What Makes It a Website?

### ✅ Frontend (The Website You See)
- **Next.js** - Modern React framework
- **TypeScript** - Type-safe code
- **Tailwind CSS** - Beautiful styling
- **Runs in browser** - Users visit your website URL

**Users will:**
- Visit your website (e.g., `truthdrop.com`)
- Browse codexes by domain (Trading, Aura Academy, Remembrance)
- Search constitutional knowledge
- Purchase codexes
- Download PDFs/ebooks after purchase

### ✅ Backend (The Server That Powers It)
- **FastAPI** - Python web framework
- **PostgreSQL** - Database (stores codexes, users, purchases)
- **Stripe** - Payment processing
- **Runs on server** - Powers the website

**Backend handles:**
- Serving codex data
- User authentication
- Purchase processing
- PDF generation
- Search functionality

### ✅ Database (Stores Everything)
- **PostgreSQL** - Relational database
- Stores: Codexes, users, purchases, domains, tags

## How It Works

1. **User visits website** → Sees homepage
2. **User browses codexes** → Sees Trading/Aura Academy/Remembrance codexes
3. **User searches** → Finds specific knowledge
4. **User purchases** → Stripe processes payment
5. **User downloads** → Gets PDF/ebook of purchased codex
